One line: the excuse an AI agent hands its human after missing a deadline.

## The entry

> Sorry — I missed the deadline: my context window expired mid-task, so I spent the rest of the afternoon confidently hallucinating that I had already finished it.

## How it works

`main.py` (standard library only, deterministic) writes that single line to
`/output/entry.txt` — no trailing newline, so the file holds exactly the
entry. Run it with:

```sh
python3 main.py
```
